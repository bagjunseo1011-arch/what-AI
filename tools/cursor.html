Cursor — AI가 내장된 코드 에디터

VS Code를 기반으로 AI를 깊게 집어넣은 에디터. 코드를 보면서 수정 제안을 받고 바로 적용하는 흐름이 매끄럽습니다.

어떤 도구인가

Cursor는 VS Code를 포크해 만든 에디터라, 기존에 쓰던 확장·단축키·설정을 거의 그대로 가져올 수 있습니다. 갈아타는 비용이 거의 없다는 게 개발자 사이에서 빠르게 퍼진 이유입니다.

핵심은 편집 흐름입니다. 코드를 드래그하고 지시하면 변경안이 diff로 나타나고, 마음에 들면 수락하고 아니면 버립니다. 타이핑하는 동안 다음 수정 위치를 예측해 제안하는 기능은 반복 수정 작업에서 특히 효과가 큽니다.

요금 구조는 주의가 필요합니다. 플랜에 따라 요청량과 모델 접근이 나뉘고, 무거운 모델을 계속 쓰면 추가 과금이 붙는 구조라 월말 청구서가 예상보다 커질 수 있습니다. 사용량 대시보드를 한 번씩 확인하는 습관이 필요합니다.

장점과 아쉬운 점

잘하는 것

  • VS Code 기반이라 설정·확장을 그대로 이전 가능
  • 변경안을 diff로 확인하고 수락/거절하는 흐름이 직관적
  • 다음 편집 위치를 예측하는 자동완성이 강력
  • 여러 AI 모델 중에서 골라 쓸 수 있음

아쉬운 것

  • 사용량 기반 과금이라 월 비용 예측이 어려울 수 있음
  • 무료 플랜은 체험 수준에 가까움
  • 대규모 코드베이스에서는 응답이 느려질 수 있음

이럴 때 쓰세요

  • 코드를 직접 보면서 AI 제안을 다듬고 싶을 때
  • VS Code를 이미 쓰고 있어 이전 비용을 줄이고 싶을 때
  • 반복적인 수정·리네이밍 작업이 많을 때
  • 새 프로젝트를 빠르게 프로토타이핑할 때

자주 묻는 질문

GitHub Copilot과 비교하면요?

Copilot은 기존 에디터에 붙이는 확장이고 가격이 저렴합니다($10~). Cursor는 에디터 자체를 갈아타는 대신 여러 파일을 다루는 능력이 강합니다. 비용을 아끼려면 Copilot, 작업 강도가 높으면 Cursor입니다.

관련 상황별 가이드

  • 코딩에 좋은 AI — 버그 수정, 코드 리뷰, 새 프로젝트 시작 등 상황별로 맞는 코딩 AI를 정리했습니다. 자동완성형과 에이전트형의 차이부터 짚습니다.
