Microsoft Copilot — 엑셀·워드·파워포인트 안에서 도는 AI

오피스 문서 안에서 직접 작동하는 AI. 엑셀 수식 작성, 워드 초안, 파워포인트 자동 생성 등 회사 업무 흐름에 그대로 붙습니다.

어떤 도구인가

Microsoft Copilot의 값어치는 "문서를 옮기지 않아도 된다"에 있습니다. 엑셀 시트 안에서 수식을 만들어 주고, 워드 문서 안에서 문단을 다시 쓰고, 아웃룩에서 메일 스레드를 요약합니다. 복사·붙여넣기 단계가 사라지는 것만으로 업무 속도가 달라집니다.

특히 엑셀에서 체감이 큽니다. "이 표에서 지역별 합계를 피벗으로 만들어 줘" 같은 지시로 수식과 피벗을 만들어 주기 때문에, 엑셀 함수를 검색하며 헤매던 시간이 크게 줄어듭니다. 회의록에서 파워포인트 초안을 만들어 내는 기능도 있습니다.

단점은 가격과 조건입니다. 오피스 안에서 쓰는 기능은 1인당 월 $30 수준의 Microsoft 365 Copilot이 필요하고, 조직 계정과 관리자 설정에 묶이는 경우가 많습니다. 개인이 웹·윈도우에서 쓰는 무료 Copilot과는 다른 제품이라는 점을 헷갈리기 쉽습니다.

장점과 아쉬운 점

잘하는 것

  • 엑셀·워드·파워포인트·아웃룩 안에서 직접 동작
  • 엑셀 수식·피벗·차트 생성이 강력
  • 메일 스레드와 팀즈 회의 요약
  • 윈도우·웹에서 쓰는 기본 Copilot은 무료

아쉬운 것

  • 오피스 연동 기능은 1인당 월 $30 수준으로 비쌈
  • 조직 관리자가 허용해야 쓸 수 있는 기능이 많음
  • 무료 Copilot과 오피스용 Copilot의 차이가 혼란스러움

이럴 때 쓰세요

  • 엑셀 함수·피벗을 자주 만들어야 하는 실무자
  • 아웃룩 메일이 하루 수십 통씩 쌓이는 직장인
  • 회의록에서 보고용 슬라이드를 만들어야 할 때
  • 이미 Microsoft 365를 쓰는 조직

자주 묻는 질문

개인이 결제해서 엑셀에 쓸 수 있나요?

Copilot Pro로 개인용 Microsoft 365 앱과 연동은 가능하지만, 기업용 기능 전부가 열리지는 않습니다. 회사 PC라면 관리자 정책에 따라 아예 막혀 있을 수도 있어 먼저 확인이 필요합니다.

관련 상황별 가이드

  • 이메일·업무 처리에 좋은 AI — 메일 답장, 회의록 정리, 일정 조율처럼 반복되는 사무 업무를 줄여 주는 AI를 정리했습니다.
  • 데이터 분석·엑셀에 좋은 AI — 엑셀 수식, 피벗, 매출 데이터 분석, 그래프 만들기에 맞는 AI를 정리했습니다. 파일을 올려서 시키는 방법과 주의점도 다룹니다.
  • 발표자료·PPT에 좋은 AI — 기획안·보고서를 슬라이드로 만들거나 PPT 초안을 빠르게 뽑아야 할 때 쓰는 AI와 실전 순서를 정리했습니다.
