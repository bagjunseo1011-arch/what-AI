Claude Code — 터미널에서 직접 코드를 고쳐 주는 AI

복사·붙여넣기 없이 프로젝트 폴더를 직접 읽고 파일을 수정·실행·테스트까지 하는 개발용 AI 에이전트입니다.

어떤 도구인가

일반 챗봇에 코딩을 시키면 코드를 복사해서 붙여 넣고, 에러가 나면 다시 복사해서 물어보는 왕복이 생깁니다. Claude Code는 그 왕복을 없앱니다. 프로젝트 폴더에서 실행하면 파일을 직접 읽고, 고치고, 테스트를 돌려 결과를 보고 다시 고칩니다.

"이 버그 고쳐 줘"처럼 파일 이름조차 모르는 요청도 처리합니다. 코드베이스를 검색해서 관련 파일을 찾아내고, 원인을 추적한 뒤 수정하는 과정을 스스로 진행합니다. 여러 파일에 걸친 리팩터링이나 테스트 작성처럼 사람이 지루해하는 작업에서 특히 값어치가 큽니다.

전제 조건이 있습니다. 터미널과 Git을 쓸 줄 알아야 하고, AI가 만든 변경사항을 읽고 판단할 수 있어야 합니다. 코딩을 아예 모르는 사람에게는 맞지 않고, 그런 경우엔 브라우저에서 되는 도구가 낫습니다.

장점과 아쉬운 점

잘하는 것

  • 프로젝트 전체를 읽고 여러 파일을 한 번에 수정
  • 테스트 실행 → 실패 확인 → 재수정까지 스스로 반복
  • VS Code·JetBrains 확장과 데스크톱 앱도 제공
  • Claude Pro/Max 구독에 포함돼 별도 결제가 불필요

아쉬운 것

  • 터미널·Git 기본 지식이 없으면 진입이 어려움
  • 큰 작업은 사용량 한도를 빠르게 소모함
  • 변경 내용을 검토 없이 수락하면 사고가 날 수 있음

이럴 때 쓰세요

  • 기존 프로젝트의 버그를 원인부터 찾아 고칠 때
  • 테스트 코드나 문서를 한꺼번에 만들어야 할 때
  • 여러 파일에 걸친 리팩터링·마이그레이션 작업
  • 낯선 코드베이스를 파악하고 설명받고 싶을 때

자주 묻는 질문

Cursor와 뭐가 다른가요?

Cursor는 편집기(IDE) 안에서 코드를 보며 작업하는 방식이고, Claude Code는 터미널에서 지시하면 알아서 여러 파일을 오가며 처리하는 방식입니다. 코드를 눈으로 보며 다듬는 쪽이면 Cursor, 통째로 맡기는 쪽이면 Claude Code가 맞습니다.

코딩을 전혀 모르는데 쓸 수 있나요?

권하지 않습니다. AI가 낸 변경을 검토할 수 없으면 문제가 생겼을 때 되돌리기 어렵습니다. 입문 단계라면 브라우저에서 되는 ChatGPT나 Claude로 개념부터 익히는 편이 낫습니다.

관련 상황별 가이드

  • 코딩에 좋은 AI — 버그 수정, 코드 리뷰, 새 프로젝트 시작 등 상황별로 맞는 코딩 AI를 정리했습니다. 자동완성형과 에이전트형의 차이부터 짚습니다.
  • 긴 문서 다루기 좋은 AI — 수십~수백 페이지 문서를 한 번에 읽히고 분석·비교해야 할 때 맞는 AI와, 문서를 나눠 넣는 요령을 정리했습니다.
