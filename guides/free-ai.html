무료: 돈 안 쓰고 어디까지 되나

결제 없이 쓸 수 있는 AI와 각각의 무료 한도를 정리했습니다. 무료 조합만으로 대부분의 개인 작업이 커버됩니다.

유료 구독을 여러 개 하기 전에, 무료 플랜 조합만으로 어디까지 되는지 확인해 볼 가치가 있습니다. 개인 용도라면 상당 부분이 무료로 커버됩니다.

핵심은 한 도구의 무료 한도를 다 쓰면 다른 도구로 넘어가는 방식입니다.

이런 상황이라면

  • 학생이라 구독료가 부담될 때
  • 결제 전에 성능을 충분히 확인하고 싶을 때
  • 가끔만 쓰는데 월정액이 아까울 때
  • 여러 도구를 비교해 보고 하나만 고르고 싶을 때

추천 AI 5개와 고르는 이유

1. Gemini · 무료 / 유료 월 $20~

무료로 열어 준 기능 범위가 가장 넓은 편입니다. 일반적인 질문·요약·초안 작성은 무료로 충분하고 유튜브 요약도 됩니다.

2. DeepSeek · 무료

웹 채팅이 무료이고 사용량 제한이 관대합니다. 수학·코딩 문제 풀이에 특히 쓸 만합니다. 다만 민감 정보는 넣지 마세요.

3. NotebookLM · 무료 / 유료 월 $20~

핵심 기능이 무료입니다. 자료를 올려서 공부하거나 정리하는 용도라면 유료 결제 없이도 충분합니다.

4. Perplexity · 무료 / 유료 월 $20~

출처가 붙는 검색이라는 핵심 기능이 무료로 계속 됩니다. 가벼운 자료 조사는 결제 없이 해결됩니다.

5. GitHub Copilot · 무료 / 유료 월 $10~

학생이나 오픈소스 메인테이너는 유료 플랜이 무료입니다. 해당된다면 신청하지 않을 이유가 없습니다.

실제로 쓰는 순서

  1. 1. 한도를 나눠 쓰기

    한 도구의 무료 한도가 차면 다른 도구로 넘어가세요. 대화형 3개(Gemini·DeepSeek·ChatGPT 무료)를 번갈아 쓰면 하루 사용량은 거의 부족하지 않습니다.

  2. 2. 용도별로 고정하기

    검색은 Perplexity, 공부는 NotebookLM, 잡다한 질문은 Gemini처럼 용도를 고정하면 각 도구의 한도가 분산됩니다.

  3. 3. 학생·창작자 혜택 확인

    GitHub Student Pack, 각종 교육용 무료 플랜을 먼저 확인하세요. 유료 기능이 무료로 열리는 경우가 꽤 있습니다.

  4. 4. 결제는 하나만 먼저

    무료로 써 보고 가장 자주 막히는 지점이 생긴 도구 하나만 결제하세요. 처음부터 여러 개를 구독하면 대부분 안 쓰게 됩니다.

주의할 점

  • 무료 플랜은 입력 데이터가 학습에 쓰일 수 있습니다. 민감한 내용은 넣지 마세요.
  • 무료 생성물은 상업적 이용이 제한되는 경우가 많습니다(이미지·음악·음성 특히).
  • 연간 결제 할인이 크므로, 1년 이상 쓸 확신이 서면 연간이 유리합니다.

자주 묻는 질문

무료만 써도 충분한가요?

개인 용도의 대부분은 충분합니다. 유료가 필요해지는 시점은 (1) 하루에 한도를 계속 넘길 때 (2) 긴 문서를 반복해서 다뤄야 할 때 (3) 상업적 이용 권리가 필요할 때입니다.
