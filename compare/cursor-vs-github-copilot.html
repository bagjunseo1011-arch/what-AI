Cursor vs GitHub Copilot — 뭘 골라야 할까

코딩 AI 입문에서 가장 흔한 고민. 월 $20 vs $10인데, 가격 차이만큼 하는 일이 다릅니다.

결론부터

월 $10 차이를 회수할 수 있느냐가 전부입니다. GitHub Copilot은 타이핑 중 다음 코드를 채워 주는 자동완성에 집중하고, 쓰던 에디터에 확장만 설치하면 끝납니다. 그 이상을 기대하지 않는다면 가격 대비 만족도가 매우 높습니다.

Cursor는 에디터 자체를 갈아타는 대신 여러 파일에 걸친 작업을 처리합니다. “이 기능 전체를 이렇게 바꿔 줘” 같은 요청이 되고, 변경안을 diff로 보며 수락/거절할 수 있습니다. 하루에 이런 요청을 여러 번 한다면 $10 차이는 금방 회수됩니다.

입문자라면 Copilot부터 시작하는 걸 권합니다. 학생이면 Copilot Pro가 무료라 더더욱 그렇습니다. 쓰다 보면 “파일 하나씩 말고 통째로 맡기고 싶다”는 순간이 오는데, 그때 Cursor나 Claude Code로 올리면 됩니다. Cursor는 사용량 기반 과금이 섞여 있어 월 비용 예측이 어렵다는 점도 감안하세요.

Cursor를 골라야 하는 경우

  • 코드를 직접 보면서 AI 제안을 다듬고 싶을 때
  • VS Code를 이미 쓰고 있어 이전 비용을 줄이고 싶을 때
  • 반복적인 수정·리네이밍 작업이 많을 때
  • 새 프로젝트를 빠르게 프로토타이핑할 때

강점 — VS Code 기반이라 설정·확장을 그대로 이전 가능 / 변경안을 diff로 확인하고 수락/거절하는 흐름이 직관적 / 다음 편집 위치를 예측하는 자동완성이 강력

약점 — 사용량 기반 과금이라 월 비용 예측이 어려울 수 있음 / 무료 플랜은 체험 수준에 가까움

GitHub Copilot를 골라야 하는 경우

  • 코딩 AI를 처음 결제해 보는 개인 개발자
  • 반복적인 보일러플레이트·테스트 코드 작성
  • VS Code나 JetBrains를 계속 쓰고 싶을 때
  • 학생 인증으로 무료 이용이 가능한 경우

강점 — 월 $10으로 유료 코딩 AI 중 진입 장벽이 가장 낮음 / 쓰던 에디터에 확장만 설치하면 끝 / 자동완성 정확도가 안정적이고 반응이 빠름

약점 — 프로젝트 전체를 아우르는 대규모 작업은 약함 / 자동완성 위주라 "알아서 다 해 줘" 방식과는 거리가 있음

자주 묻는 질문

Cursor로 옮기면 기존 VS Code 설정을 다시 해야 하나요?

아닙니다. Cursor는 VS Code를 포크한 에디터라 확장·단축키·설정을 가져올 수 있습니다. 이전 비용이 거의 없다는 게 빠르게 퍼진 이유입니다.

둘 다 쓰는 건 의미가 없나요?
